# 浏览器隔离对照实验计划 V0.1

**性质：测试方案，不包含声称已经完成的实测结果。**

## 测试前记录
操作系统及版本、浏览器及版本、扩展列表、默认语言和字体、网络环境、日期与时间、测试网站版本；不要上传 Cookie、令牌、指纹原始唯一标识或私有网络信息。

## 实验 A：Chrome 两个 Profile
1. 在 Profile A 中打开自建测试页面，写入自定义测试键（Cookie、LocalStorage、IndexedDB），记下状态。
2. 在 Profile B 打开相同自建页面，检查这些键是否存在。
3. 使用完全相同的无害本地 Canvas 测量和 User-Agent / 平台特征记录，比较两者是否相同。
4. 清除测试数据。记录符合预期和意外差异。

## 实验 B：Firefox 同一 Profile 的两个 Container
1. 使用两个容器访问自建测试页面。
2. 记录存储键可见性；不以是否共享 IP 推断会话数据隔离失效。
3. 对比设备相关可观察信息，记录 Firefox 版本和是否启用抗跟踪功能。

## 实验 C：不同浏览器
1. 在同设备同网络上分别打开 Chrome 与 Firefox 的自建测试页面。
2. 对比登录状态、浏览器引擎相关 API、实际出口 IP 是否共享。
3. 不把不同指纹值直接解释为不同真实设备。

## 网络检查
分别确认 Chrome、Firefox 与需要使用的 CLI/IDE 客户端是否遵循预期的网络、代理及 DNS 配置。WebRTC 检查只针对其所在浏览器与当次配置，不外推到所有程序。
