# 技术主张审计表（初版）

| 原稿主张 | 分类 | 审查结论 | 发表建议 |
|---|---|---|---|
| 清 Cookie 不会自动清除所有站点存储 | 原理成立 | 清除范围取决于浏览器操作及工具 | 保留、具体说明 |
| IndexedDB 普遍写入 device_id | 平台行为推测 | 不适用于所有网站，缺少目标网站数据 | 改为“可能” |
| ETag 能作为历史跟踪信号 | 已知历史技术 | 实际限制取决于缓存分区和浏览器版本 | 加版本限定 |
| TLS Session Ticket 切 IP 后必然暴露同设备 | 过度断言 | 网络状态分区及复用条件未充分考虑 | 删除必然结论 |
| FedCM 任意脚本可获主账号身份 | 过度断言 | 应结合身份提供商交互和权限边界 | 重写 |
| 同一无痕会话的多个窗口共享临时状态 | 浏览器行为 | 应依具体浏览器和版本核对 | 保留并验证 |
| 无痕模式在 Stripe 必然加欺诈分 | 未经证实的平台规则 | 未获公开证据 | 删除 |
| Chrome 不同 Profile 的站点存储隔离 | 原理成立 | 但 OS、IP、部分指纹特征仍可重合 | 保留并解释边界 |
| Firefox Containers 是独立设备 | 不成立 | 主要隔离站点数据 | 明确纠正 |
| 中文字体存在可证明设备在中国 | 不成立 | 字体与地理位置没有确定关系 | 删除 |
| FontFaceSet.check=false 证明字体不存在 | API 语义错误 | check 不等于系统字体安装枚举 | 修正 |
| 重写 Function.prototype.toString 后零篡改痕迹 | 未验证且技术风险高 | 可能产生不一致与功能影响 | 不作为产品保证 |
| Firefox 字体可见性修改完全不影响中文排版 | 需要版本实验 | 缺少兼容性和回退字体结果 | 暂列待验证 |
| 清空事件日志可安全消除痕迹 | 不当建议 | 损失审计证据且不等于安全 | 删除 |
| Chrome IP/WebRTC 测试代表 Claude Code 实际连接 | 不成立 | CLI 网络配置可能不同 | 拆分测试 |

**证据标签**：官方确认 / 已知机制 / 可重复观察 / 合理推断 / 未验证 / 错误表述。
