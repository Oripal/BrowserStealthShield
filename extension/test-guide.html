本地位置隐私自检

本扩展不向外部服务器传输位置或指纹数据。由于扩展自己的页面不能代表普通网站，测试需要在本机运行普通 HTTP 页面。

  1. 在源码根目录打开终端，运行 python -m http.server 8765。
  2. 在 Chrome 中打开 http://localhost:8765/tests/privacy-check.html。
  3. 先检查网站权限状态；如需尝试定位，必须自己点击测试按钮。
  4. 启用/恢复扩展里的定位阻止、WebRTC 限制后，刷新测试页并重复对照。
测试页只显示“允许/拒绝/失败”与 ICE 候选类型数量，不显示经纬度和原始 IP。WebRTC 测试不使用 STUN 服务，因此不能证明公网 IP 不会被第三方获取。单独的 Chrome 站点许可、企业管理设置或其他扩展可能影响结果。
